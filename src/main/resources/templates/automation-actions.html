Actions

What an automation can run. An action is a skill plus how it works: on a pull request or on a branch, what it produces and what it does with the result. Projects then bind an action to a trigger in their Automations tab.

Skills

A skill is a SKILL.md with front matter (name, description, optional extends). Installed skills are prompt-only: they add instructions and never widen what the agent may do. A built-in skill cannot be replaced.

Installing is off. Set PETRI_SKILLS_INSTALLED_ROOT to a writable directory to enable it.
