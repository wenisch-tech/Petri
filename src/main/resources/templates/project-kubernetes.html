Pod

What changes in a pod

The pod is the sandbox: commands, tests and git run there. Package installs are disabled, so the image must contain the tools. Sandbox profiles still set the test timeout, output limit and variables; their image and resource limits do not apply. Package sources are not applied yet.

Delete the workspace volume

Removes the pod, the volume with the repository and the credentials from the cluster. This cannot be undone.
