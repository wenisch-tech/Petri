Project

Variables this project adds to terminal commands, approved tests and package installs.

One NAME=value per line. Values are encrypted and never shown again: a saved variable appears as NAME=********; leave that as it is to keep the value, or type a new one to replace it. Remove the line to delete it.

How these combine

Commands start from a clean environment. The sandbox profile's variables are applied first, then these, so a name set here wins. Names such as PATH and HOME are reserved.
